# Fenrir for VK — ветка синхронизации с апстримом

Эта ветка держится **чистой копией оригинального проекта [Fenrir for VK](https://github.com/umerov1999/Fenrir-for-VK)** (GPL-3.0) и нужна только для слияния с будущими версиями апстрима. Ничего своего сюда не коммитим.

Все доработки форка (музыка из локальных папок, единый онлайн+офлайн плейлист, ночное автоскачивание, прозрачное кэширование, честный шафл по всей библиотеке и т.д.) живут в ветке [`ci/offline-audio-and-fair-shuffle`](https://github.com/evil-raider/Fenrir-for-VK/tree/ci/offline-audio-and-fair-shuffle) — там же подробный README со списком отличий.

Инструкция по локальной сборке и скриншоты — в README апстрима.
