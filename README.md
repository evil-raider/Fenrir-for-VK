# Fenrir for VK — форк: музыка онлайн + оффлайн

Форк открытого VK-клиента **[Fenrir for VK](https://github.com/umerov1999/Fenrir-for-VK)** (GPL-3.0). Инструкция по локальной сборке и скриншоты — в README апстрима.

**Цель форка:** (1) воспроизведение локальных треков из своих папок, (2) единый бесшовный плейлист online (VK) + offline (папки), (3) автоскачивание всей личной онлайн-музыки, (4) прозрачное кэширование прослушиваемых онлайн-треков.

Весь функционал — в ветке [`ci/local-folders`](https://github.com/evil-raider/Fenrir-for-VK/tree/ci/local-folders); APK собирается автоматически на GitHub Actions при каждом пуше в эту ветку (артефакт `ci-out`, логи — в ветке `ci-logs`).

## Что сделано

### 1. Музыка из собственных папок на телефоне
Можно указать дополнительную папку («Папка с локальной музыкой»), из которой Fenrir тоже показывает и играет треки — как ещё один источник музыки наравне с VK и папкой загрузок. Файлы распознаются по ID3-тегам (исполнитель/название), а если тегов нет — по имени файла в формате «Исполнитель - Название». Вложенные подпапки сканируются рекурсивно (до 12 уровней). Учитываются форматы из настройки «audio_ext» (по умолчанию mp3/ogg/flac/opus) и всегда дополнительно m4a/wav/aac.

### 2. Единый список «Моя музыка+оффлайн» (VK + офлайн)
В главном списке «Моя музыка» треки из VK и локальные файлы из папок показаны одним общим списком — слушать, листать и перемешивать можно всё сразу, без разрывов при переходе между онлайн- и офлайн-треками. Список автоматически догружается целиком в фоне (VK отдаёт его страницами по 100 треков), поэтому перемешивание и поиск работают по всей библиотеке, а не по первой сотне. В отдельных VK-плейлистах локальные треки не подмешиваются, но если конкретный трек там окажется недоступен (удалён/заблокирован), плеер сразу найдёт его локальную копию на диске по имени файла — при первой же попытке воспроизведения.

### 3. Приоритет локальной копии
Если трек уже скачан на телефон, Fenrir всегда играет именно скачанный файл, а не тянет его заново из интернета — экономия трафика и работа без сети. Если файл удалили вручную мимо приложения, плеер это обнаруживает и автоматически возвращается к онлайн-версии. И наоборот: если трек удалён/заблокирован в VK, а его локальную копию положили в папку вручную (с именем из уведомления — см. п. 6), плеер подхватит её сразу, при первой попытке воспроизведения, без пересканирования списка.

### 4. Ночное автоскачивание всей «Моей музыки»
Раз в сутки, примерно в 5 утра, Fenrir в фоне докачивает на телефон все треки из «Моей музыки», которых там ещё нет. Уже скачанное повторно не качается. Три независимых переключателя в настройках: включить/выключить автоскачивание, только по Wi-Fi, только на зарядке. Прогресс — одно общее уведомление «X / N», а не отдельное на каждый файл. Есть также кнопка «Ручной запуск» — запускает синхронизацию немедленно, игнорируя условия по времени/Wi-Fi/зарядке.

### 5. Прозрачное кэширование при прослушивании
Когда играет онлайн-трек из «Моей музыки», Fenrir незаметно сохраняет его на телефон прямо во время прослушивания — часто слушаемое постепенно само оседает в офлайне без отдельного нажатия «скачать». Управляется штатной настройкой «Принудительно слушать из загрузок». Кэширование идёт через отдельный тихий воркер: одно беззвучное уведомление без всплывающего окна видно только пока идёт скачивание и исчезает по завершении; при ошибке остаётся тихое уведомление с текстом ошибки.

### 6. Уведомление о недоступном треке
Если трек удалён или заблокирован в VK и у него нет ни рабочей онлайн-ссылки, ни локальной копии — при любой попытке его проиграть или скачать в шторке появляется уведомление с единым текстом:

> **Отсутствует локальная копия недоступного онлайн файла. Ожидается имя «Исполнитель - Название.mp3»**

Имя файла формируется из тегов трека — именно в таком формате автоскачивание и кэширование сохраняют файлы, и под таким именем плеер подхватит вручную добавленную копию сразу, при первой же попытке воспроизведения. Уведомление появляется в трёх местах: плеер (при воспроизведении), прозрачное кэширование и ночная синхронизация.

### 7. Кнопка «Музыка» в нижней панели
Быстрый доступ к «Моей музыке+оффлайн» прямо из докбара — первая (крайняя левая) кнопка, перед «Лентой».

### 8. Папки
Всё скачанное из VK — ручное «Скачать», ночное автоскачивание и прозрачное кэширование — попадает в одну папку: «Папка с загруженной музыкой» (штатная настройка каталога музыки). Плюс одна дополнительная «Папка с локальной музыкой» для собственных файлов пользователя. Обе папки участвуют в сканировании для единого списка.

### 9. Вход в VK — только по QR-коду
Обычный вход по логину и паролю в этой сборке не работает — это ограничение на стороне VK для сторонних клиентов, а не баг форка. Рабочий способ входа — кнопка «Войти по QR-коду» на экране входа.

## Риски
1. **VK может закрыть доступ к музыке через сторонние клиенты.** Онлайн-часть работает через механизм апстрима (эмуляция официального клиента); автоскачивание использует те же ссылки, что и обычное воспроизведение.
2. **Тяжёлая нативная сборка (ffmpeg/NDK/CMake).** Полностью перенесена на GitHub Actions, но остаётся самым хрупким местом при обновлении версий Android SDK/NDK.
3. **GPL-3.0 (copyleft).** Код открыт, изменения зафиксированы в истории коммитов, копирайт-уведомления апстрима сохранены.
