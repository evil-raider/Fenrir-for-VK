# Fenrir for VK — форк: музыка онлайн + оффлайн

Форк открытого VK-клиента **[Fenrir for VK](https://github.com/umerov1999/Fenrir-for-VK)** (GPL-3.0).

**Цель форка:** (1) воспроизведение локальных треков из своих папок, (2) единый бесшовный плейлист online (VK) + offline (папки), (3) автоскачивание всей личной онлайн-музыки, (4) прозрачное кэширование прослушиваемых онлайн-треков.

Весь функционал — в ветке [`ci/local-folders`](https://github.com/evil-raider/Fenrir-for-VK/tree/ci/local-folders); APK собирается автоматически на GitHub Actions при каждом пуше в эту ветку (артефакт `ci-out`, логи — в ветке `ci-logs`).

## Что сделано

### 1. Музыка из собственных папок на телефоне
Можно указать дополнительную папку («Папка с локальной музыкой»), из которой Fenrir тоже показывает и играет треки — как ещё один источник музыки наравне с VK и папкой загрузок. Файлы распознаются по ID3-тегам (исполнитель/название), а если тегов нет — по имени файла в формате «Исполнитель - Название». Вложенные подпапки сканируются рекурсивно (до 12 уровней). Учитываются форматы из настройки «audio_ext» (по умолчанию mp3/ogg/flac/opus) и всегда дополнительно m4a/wav/aac.

### 2. Единый список «Моя музыка+оффлайн» (VK + офлайн)
В главном списке «Моя музыка» треки из VK и локальные файлы из папок показаны одним общим списком — слушать, листать и перемешивать можно всё сразу, без разрывов при переходе между онлайн- и офлайн-треками. Список автоматически догружается целиком в фоне (VK отдаёт его страницами по 100 треков), поэтому перемешивание и поиск работают по всей библиотеке, а не по первой сотне. В отдельных VK-плейлистах локальные треки не подмешиваются, но если конкретный трек там недоступен (удалён/заблокирован), плеер попробует найти его локальный аналог по исполнителю и названию.

### 3. Приоритет локальной копии
Если трек уже скачан на телефон, Fenrir всегда играет именно скачанный файл, а не тянет его заново из интернета — экономия трафика и работа без сети. Если файл удалили вручную мимо приложения, плеер это обнаруживает и автоматически возвращается к онлайн-версии.

### 4. Ночное автоскачивание всей «Моей музыки»
Раз в сутки, примерно в 5 утра, Fenrir в фоне докачивает на телефон все треки из «Моей музыки», которых там ещё нет. Уже скачанное повторно не качается. Три независимых переключателя в настройках: включить/выключить автоскачивание, только по Wi-Fi, только при зарядке. Прогресс — одно общее уведомление «X / N», а не отдельное на каждый файл.

### 5. Прозрачное кэширование при прослушивании
Когда играет онлайн-трек из «Моей музыки», Fenrir незаметно сохраняет его на телефон прямо во время прослушивания — часто слушаемое постепенно само оседает в офлайне без отдельного нажатия «скачать». Управляется штатной настройкой «Принудительно слушать из загрузок». Кэширование идёт через отдельный тихий воркер: одно беззвучное уведомление видно только пока идёт скачивание и исчезает по завершении; при ошибке остаётся тихое уведомление с текстом ошибки.

### 6. Уведомление о полностью недоступном треке
Если трек удалён или заблокирован в VK и у него нет ни рабочей онлайн-ссылки, ни локальной копии — при попытке проиграть его показывается уведомление с исполнителем и названием и подсказкой, каким именем или тегами должен обладать файл, чтобы плеер сам подхватил его из папок при следующем сканировании.

### 7. Папки
Всё скачанное из VK — ручное «Скачать», ночное автоскачивание и прозрачное кэширование — попадает в одну папку: «Папка с загруженной музыкой» (штатная настройка каталога музыки). Плюс одна дополнительная «Папка с локальной музыкой» для собственных файлов пользователя. Обе папки участвуют в сканировании для единого списка.

### 8. Вход в VK — только по QR-коду
Обычный вход по логину и паролю в этой сборке не работает — это ограничение на стороне VK для сторонних клиентов, а не баг форка. Рабочий способ входа — кнопка «Войти по QR-коду» на экране входа.

## Риски
1. **VK может закрыть доступ к музыке через сторонние клиенты.** Онлайн-часть работает через механизм апстрима (эмуляция официального клиента); автоскачивание использует те же ссылки, что и обычное воспроизведение.
2. **Тяжёлая нативная сборка (ffmpeg/NDK/CMake).** Полностью перенесена на GitHub Actions, но остаётся самым хрупким местом при обновлении версий Android SDK/NDK.
3. **GPL-3.0 (copyleft).** Код открыт, изменения зафиксированы в истории коммитов, копирайт-уведомления апстрима сохранены.

<b>Инструкция по сборке:</b><br>
Требуется:<br>
  1. Android Studio Quail 3 2026.1.3 или выше. Kotlin 2.4.*<br>
  2. Android SDK 37<br>
  3. Android NDK 30.0.15729638<br>
  4. CMake 4.1.2<br>
  5. Diffutils
  
  Если не работает музыка в Fenrir Kate, обновите kate_receipt_gms_token в app.build_config.<br>
  Взять токен можно из Kate Mobile Extra Mod<br>
  
<b>Компиляция:</b>

  1. Для релизных сборок вам нужен сертификат.<br>
  keytool -genkey -v -keystore Fenrir.keystore -alias fenrir -storetype PKCS12 -keyalg RSA -keysize 2048 -validity 10000<br>
  2. Вариант 1. Далее нужно собрать нативную библиотеку:<br>
  Создать папку compiled_native, раскомментировать [include ":native"] в settings.gradle<br>
  cd native<br>
  ./ffmpeg.sh<br>
  после синхронизации репозитория ffmpeg введите min sdk version<br>
  после сборки ffmpeg соберите native в Android Studio и поместите native-release.aar в compiled_native<br>
  3. Вариант 2. Далее нужно собрать нативную библиотеку:<br>
  Раскомментировать [include ":native"] в settings.gradle<br>
  Раскомментировать [implementation project(":native")] в app*/build.gradle<br>
  Удалить [implementation fileTree('../compiled_native') { include '*.aar' }] в app*/build.gradle<br>
  cd native<br>
  ./ffmpeg.sh<br>
  после синхронизации репозитория ffmpeg введите min sdk version<br>
  после сборки ffmpeg можете собирать проект<br>
  4. Выберите flavor - fenrir или kate и Debug или Release и соберите apk :)<br>

Локальный медиа сервер https://github.com/umerov1999/FenrirMediaServer/releases <br>
