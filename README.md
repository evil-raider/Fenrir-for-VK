# Fenrir for VK — форк: музыка онлайн + оффлайн

Форк открытого VK-клиента **[Fenrir for VK](https://github.com/umerov1999/Fenrir-for-VK)** (GPL-3.0). Инструкция по локальной сборке и скриншоты — в README апстрима.

**Цель форка:** (1) воспроизведение локальных треков из своих папок, (2) единый бесшовный плейлист online (VK) + offline (папки), (3) автоскачивание всей личной онлайн-музыки, (4) прозрачное кэширование прослушиваемых онлайн-треков.

Весь функционал — в ветке [`ci/local-folders`](https://github.com/evil-raider/Fenrir-for-VK/tree/ci/local-folders); APK собирается автоматически на GitHub Actions при каждом пуше в эту ветку (артефакт `ci-out`, логи — в ветке `ci-logs`).

Ниже перечислены все отличия форка от оригинального Fenrir — описано только текущее состояние.

## Изменения относительно оригинального Fenrir

### 1. Музыка из собственных папок
Можно указать дополнительную папку («Папка с локальной музыкой»), из которой Fenrir показывает и играет треки — как ещё один источник наравне с VK и папкой загрузок. Файлы распознаются по ID3-тегам (исполнитель/название), а без тегов — по имени файла в формате «Исполнитель - Название». Вложенные подпапки сканируются рекурсивно (до 12 уровней).
- **В оригинальном Fenrir** локальные файлы доступны только на отдельной вкладке «На устройстве»; отдельной пользовательской папки-источника для музыки нет.
- **Форматы:** оригинал берёт список расширений только из настройки «audio_ext» (по умолчанию mp3/ogg/flac/opus) — форк всегда дополнительно учитывает m4a/wav/aac.

### 2. Единый список «Моя музыка+оффлайн» (VK + офлайн)
В главном списке треки из VK и локальные файлы показаны вместе — слушать, листать и перемешивать можно всё сразу, без разрывов при переходе между онлайн- и офлайн-треками. Вкладка называется «Моя музыка+оффлайн».
- **В оригинальном Fenrir** «Моя музыка» содержит только VK-треки (и вкладка называется «Моя музыка»), локальные файлы в неё не попадают.
- **Полная догрузка списка.** Форк автоматически догружает всю библиотеку в фоне (VK отдаёт её страницами по 100 треков), поэтому перемешивание и поиск работают по всем трекам сразу. В оригинале, чтобы охватить всю библиотеку, список нужно вручную долистать до конца.
- **Честное случайное воспроизведение.** «Вперемешку» охватывает все треки списка и распределяет их равномерно; порядок запоминается между сессиями — приложение помнит уже прозвучавшие треки текущего «прохода» и сначала ставит ещё не звучавшие, а после полного прохода начинает новый. **В оригинальном Fenrir** очередь плеера ограничена ~200 треками, а порядок перемешивания не сохраняется между запусками, поэтому «случайно» крутится внутри начала библиотеки: одни треки повторяются, другие не выпадают вовсе.
- **Локальный аналог в чужих плейлистах.** В отдельных VK-плейлистах локальные треки не подмешиваются, но если трек там недоступен (удалён/заблокирован), плеер сразу находит его локальную копию на диске по имени файла. **В оригинале** такого поиска локального аналога нет.

### 3. Приоритет локальной копии
Если трек скачан на телефон, Fenrir играет именно локальный файл, а не тянет его из сети — экономия трафика и работа без сети. Если файл удалили вручную мимо приложения, плеер обнаруживает это и возвращается к онлайн-версии. И наоборот: если трек удалён/заблокирован в VK, а копию положили в папку вручную (с именем из уведомления, см. п. 6), плеер подхватывает её сразу, при первой попытке воспроизведения — в том числе из вложенной подпапки.
- **В оригинальном Fenrir** недоступный онлайн-трек не заменяется локальной копией, найденной по имени файла.

### 4. Ночное автоскачивание всей «Моей музыки»
Раз в сутки, примерно в 5 утра, Fenrir в фоне докачивает все треки из «Моей музыки», которых ещё нет на телефоне; уже скачанное не трогает. Три независимых переключателя: включить автоскачивание, только по Wi-Fi, только на зарядке. Прогресс — одно общее уведомление «X / N». Есть кнопка «Ручной запуск» — синхронизация немедленно, игнорируя условия по времени/Wi-Fi/зарядке.
- **В оригинальном Fenrir** массового автоскачивания всей библиотеки нет — только ручное «Скачать» для отдельных треков.

### 5. Прозрачное кэширование при прослушивании
Когда играет онлайн-трек из «Моей музыки», Fenrir незаметно сохраняет его на телефон прямо во время прослушивания — часто слушаемое само оседает в офлайне без отдельного нажатия «скачать». Управляется штатной настройкой «Принудительно слушать из загрузок». Идёт через отдельный тихий воркер: одно беззвучное уведомление без всплывающего окна, пока идёт скачивание, и исчезает по завершении; при ошибке остаётся тихое уведомление с текстом ошибки.
- **В оригинальном Fenrir** этой функции нет: онлайн-трек сохраняется в офлайн только явным «Скачать».

### 6. Уведомление о недоступном треке
Если трек удалён/заблокирован в VK и у него нет ни рабочей онлайн-ссылки, ни локальной копии — при попытке проиграть или скачать в шторке появляется уведомление с единым текстом:

> **Отсутствует локальная копия недоступного онлайн файла. Ожидается имя «Исполнитель - Название.mp3»**

Имя файла формируется из тегов трека — в таком же формате автоскачивание и кэширование сохраняют файлы, и под таким именем плеер подхватит вручную добавленную копию. Уведомление появляется в трёх местах: плеер (при воспроизведении), прозрачное кэширование и ночная синхронизация.
- **В оригинальном Fenrir** такого уведомления нет.

### 7. Кнопка «Музыка» в нижней панели
«Моя музыка+оффлайн» открывается прямо из докбара — первой (крайней левой) кнопкой, перед «Лентой».
- **В оригинальном Fenrir** быстрого доступа к музыке из нижней панели на первой позиции нет.

### 8. Папки для музыки
Всё скачанное из VK — ручное «Скачать», ночное автоскачивание и прозрачное кэширование — попадает в одну «Папку с загруженной музыкой» (штатная настройка каталога музыки). Плюс одна «Папка с локальной музыкой» — для собственных файлов пользователя. Обе участвуют в сканировании для единого списка.
- **Относительно оригинала** добавлена отдельная пользовательская локальная папка-источник; каталог загрузок остаётся штатным.

### 9. Вход в VK — только по QR-коду
Обычный вход по логину и паролю в этой сборке не работает — это ограничение на стороне VK для сторонних клиентов, а не проблема кода форка. Рабочий способ входа — кнопка «Войти по QR-коду» на экране входа.

### 10. Точное определение недоступных треков
Статус недоступности («удалён правообладателем») перепроверяется отдельным запросом к VK по ID (пачками): VK возвращает только реально существующие треки, поэтому окончательно недоступным считается лишь тот, кого в ответе нет вовсе, а треки с временно пустой ссылкой дорезолвливаются и остаются рабочими.
- **В оригинальном Fenrir** трек с пустой/недоступной ссылкой сразу считается недоступным, из-за чего при обычном сетевом сбое или просроченном URL живые треки ошибочно выглядят удалёнными.

## Риски
1. **VK может закрыть доступ к музыке через сторонние клиенты.** Онлайн-часть работает через механизм апстрима (эмуляция официального клиента); автоскачивание использует те же ссылки, что и обычное воспроизведение.
2. **Тяжёлая нативная сборка (ffmpeg/NDK/CMake).** Полностью перенесена на GitHub Actions, но остаётся самым хрупким местом при обновлении версий Android SDK/NDK.
3. **GPL-3.0 (copyleft).** Код открыт, изменения зафиксированы в истории коммитов, копирайт-уведомления апстрима сохранены.
